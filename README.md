### 📊 Machine Learning (`./machine-learning`)

Ordered from most recent to oldest:

- **Fraudulent Job Ads Detection** (English 🇺🇸)  
  Applied dimensionality reduction using neural networks (autoencoders) to improve predictive analysis of fraudulent job postings.  
  Includes pre-processing (feature selection, encoding, scaling), class balancing with SMOTE-NC, logistic regression baseline and comparison of performance after constructing a latent representation.  
  [View Project](./machine-learning/03-fraudulent-job-ads-detection)

- **Credit Risk Analysis** (English 🇺🇸)  
  Applied statistical and machine learning techniques to assess credit risk based on financial data.  
  [View Project](./machine-learning/02-credit-risk-analysis)

- **Stellar Age Prediction (Predicción de edades estelares)** (Spanish 🇪🇸)  
  Developed predictive models to estimate stellar ages using astrophysical datasets. Combines astronomy knowledge with machine learning methods, as part of the *Experimental Astrophysics (UC)* course.  
  [View Project](./machine-learning/01-stellar-age-prediction)

## ⚙️ Technologies Used

- **Languages**: Python  
- **Frameworks & UI**: Streamlit  
- **APIs & LLMs**: Google GenAI SDK (Gemini) and Google API Client (Gmail API)  
- **ML & Data Libraries**: pandas, NumPy, scikit-learn, matplotlib, seaborn, astropy, scipy, imbalanced-learn, keras and tensorflow  
- **Tools**: Jupyter Notebook and kagglehub

---

## 🔑 Concepts Applied

- **Generative AI & Agents**: LLM integration, prompt engineering, structured JSON output mode, context-aware response generation and session caching  
- **Software Architecture**: Object-Oriented Design (OOP), separation of concerns (UI, AppState and Backend) and OAuth2 authentication flow  
- **Machine Learning**: Supervised learning (classification and regression), dimensionality reduction (autoencoders) and feature importance analysis  
- **Data Engineering**: Data cleaning, scaling, One-Hot encoding, handling missing values and class balancing (SMOTE-NC)  
- **Model Evaluation**: Hyperparameter tuning (GridSearchCV, RandomizedSearchCV), accuracy, precision, recall, F1-score and confusion matrix evaluation  
- **Domain Applications**: Financial risk assessment, recruitment scam detection and astrophysical data processing (FITS files)
